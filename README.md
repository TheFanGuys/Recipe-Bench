# The Recipe Bench

Recipe app with 368 recipes, sauces and rubs. Scale any recipe up or down, adjust for high elevation, build a shopping list, convert units and keep a spice rack. Replaced the old BakingPro app.

**Open it:** https://thefanguys.github.io/Recipe-Bench/

Your data is saved on your phone only (in Safari). It is not stored in this repo. If you used BakingPro in Safari itself, its favorites, shopping list and elevation setting carry over. A home-screen icon keeps its own separate storage, so data from a BakingPro home-screen icon does not.

Single-file app (index.html), no build step. Hosted on GitHub Pages. Upload a new index.html to update it.
